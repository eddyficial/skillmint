Quickstart SOP: Review A Small Change

This internal sample teaches a simple review routine for a small code or document change.

Prepare

Read the stated goal, identify the changed files, and confirm the expected output before reviewing details.

Review

Check the smallest behavior first, then inspect edge cases, safety gates, and whether tests cover the changed behavior.

Validate

Run the narrowest relevant test first. If it passes, run the broader suite that covers the touched area.

Report

Summarize the result, list the exact verification command, and call out any remaining risk or missing prerequisite.
